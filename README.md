# javascript-lotto-precourse

# 로또 구입 금액을 입력받고, 로또의 담청 내역을 출력하는 프로그래밍

# 기능 요구 사항

1. 입력 기능

1-1) 로또 구입 금액 입력

- 0이 아닌 1000원 단위로 떨어지는 금액 입력해야 한다.
- 최소금액은 1000원이며, 최대금액은 1000000원이다.

1-2) 당첨 번호 입력

- 번호는 1~45까지 사이의 숫자를 입력해야 한다.
- 6개의 번호를 쉼표 구분자(,) 로 입력

1-3) 보너스 번호 입력

- 1~45사이의 숫자를 입력해야 한다.
- 당첨 번호 입력에서 입력하지 않았던 번호를 입력해야 한다.

2. 출력 기능

1-1) 로또 수량 출력

- 입력한 금액을 바탕으로 로또 수량을 계산한다.

1-2) 로또 번호 출력

- 로또 수량에 맞게 로또 번호를 출력한다.
- 로또 번호는 중복되지 않은 6개의 번호로 이루어져 있다.
- 로또 번호는 오름차순으로 정렬한다.

1-3) 당첨 내역 출력

- 발행이 된 로또 번호를 기준으로 3개 번호 ~ 6개 번호일치 여부로 당첨을 결정한다.
- 총 5가지의 경우의 수가 있으며 해당이 되지 않더라도 출력을 한다.
- 출력 형식은 경우의수 - 해당이 된 갯수 예륻 들어, 3개 일치 (5,000원) - 1개

1-4) 수익률 출력

- 로또를 구매한 비용과 로또 당청금으로 수익률을 계산한다.
- 소수 2번째 자리에서 반올림 한다.(ex. 100.0%, 51.5%, 1,000,000.0%)

# 예외 사항

1. 입력 기능

1-1) 로또 구입 금액 입력

- 빈문자열울 압력한 경우
- 숫자가 아닌 다른 타입을 입력한 경우
- 1000원 미만 입력하는 경우(최소)
- 1000000 초과 입력하는 경우(최대)
- 1000 으로 나누어 떨어지지 않는 경우

1-2) 당첨 번호 입력

- 빈문자열을 입력한 경우
- 쉼표 구분자(,)가 아닌 다른 구분자로 번호를 구분한 경우
- 입력한 값이 숫자가 아닌 다른 타입의 값이 있을 경우
- 6개의 숫자를 입력하지 않았을 경우
- 입력한 숫자에서 중복된 숫자가 있는 경우
- 입력한 숫자가 1~45 범위를 벗어난 경우

1-3) 보너스 번호 입력

- 빈문자열을 입력한 경우
- 숫자가 아닌 다른 타입을 입력한 경우
- 입력한 숫자가 1~45 범위를 벗어난 경우

2. 출력 기능

1-1) 로또 번호 출력

- 로또 번호의 개수가 6개가 넘어간 경우
- 중복된 번호가 있는 경우
- 숫자가 아닌 값이 있는 경우
- 번호가 1 ~ 45 사이에 있지 않은 경우
- 번호가 오름차순으로 정렬되어 있지 않은 경우

## 기능 요구 사항

| 클래스 / 기능 | 기능             | 설명                                                                                               |
| ------------- | ---------------- | -------------------------------------------------------------------------------------------------- |
| `LottoTicket` | 로또 수량 계산   | 1000원 단위로 로또 수량계산                                                                        |
| `LottoTicket` | 로또 번호 생성   | 중복 없는 6개 번호 생성, 오름차순 정렬                                                             |
| `LottoResult` | 당첨 번호 입력   | 1~45 사이 숫자, 6개 번호 입력                                                                      |
| `LottoResult` | 보너스 번호 입력 | 1~45 사이 숫자, 당첨 번호와 중복되지 않음                                                          |
| `LottoResult` | 당첨 내역 출력   | 3~6개 번호 일치 여부 출력, 총 5가지 경우, 예: `3개 일치 (5,000원) - 1개`                           |
| `LottoResult` | 수익률 계산      | 구매 비용 대비 당첨금 수익률 계산, 소수점 2번째 자리 반올림, 예: `100.0%`, `51.5%`, `1,000,000.0%` |
